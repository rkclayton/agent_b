# Agent_b v1.28.0

## Fixed

- Update works from v1.24.0. The installer was being handed a folder it refused, so every attempt from that version failed in under a second with nothing readable on screen. If you are on v1.24.0, install this one by hand from the release page; updating will work from here on.
- A failed install now shows the installer's own sentence and the path to its transcript, instead of only saying that the install stopped.
- No console window is left behind by an install, whether it succeeds or fails.
- Testing a server no longer lands on a different port than the one you typed. An address that answers at all now ends the search, including one that asks for an API key, and a server that lists no models never wins over one that does.
- A wrong path on the right port is still searched properly, so typing an address with a path that has no model API still finds the one that does.
- Pressing Remove on a collapsed connection did nothing visible. The reason now appears on the row you pressed, and the row opens so the settings it concerns are visible too.
- The confirmation popover stays with the control that raised it however far the settings sheet is scrolled.

## Added

- You can send a message to Agent_b from your phone and hear back what came of it. A new guide walks through pairing, both Shortcuts, and the three ways it can fail. Agent_b still listens only on its own machine; reaching it from anywhere else is something you set up yourself, and the guide says exactly how.
- Sending a message can carry a key that makes it safe to retry: the same key twice gets the first answer back and starts no second run.
- A message that names no chat lands in one called Siri, created once and reused.

## Changed

- While Test looks for a model API it says which address it is trying and what that address answered, counting addresses tried against the total.
- The model is always a dropdown. Empty, it says to press Test; filled, it lists what the server offers with the first one selected; and it always offers a way to type a name by hand for a server that cannot list its own models.
- A new connection starts with no address and no model instead of a guess and a placeholder.
- Choosing a model fills in what belongs with it, and never overwrites a name you typed yourself.
- The result of a Test appears once, under the address it is about. The row shows one word instead of the whole sentence.
- A stored API key is a note beside an empty field rather than a masked value in an input, and a key that still holds that placeholder is refused rather than quietly discarded.
- A connection that cannot be removed says what to do about it: which chat to close, where to change an assignment, or that you need a second connection first.

## Under the hood

- Nothing this project starts puts a window on your screen, and a check now fails the tests if a new one would. Three windows are deliberate and stay: a background launch that failed reappears so it can report, opening the browser is the point of launching, and the console you start it in is yours to close.
- The release tests now replay the exact command line that older installations send, so the version most people are on is the one the update path is proved against.

## Known

- The connections page reports what the connected server says about itself; nothing in this release changes which models a server offers.
