# Agent_b v1.24.0

## Changed

- The model switcher now shows which model each connection offers, not just a label, a host and a state.
- A long model name is shown in full rather than cut off; a file-based model shows its filename, with the full path on hover.
- A connection that has never been tested says so instead of naming a model called "model".
- Fenced code blocks keep their language and show it quietly; a block with no language looks exactly as before.
- The copy control on a code block is no longer a paperclip, which meant "attach a file" elsewhere in the window. It is two overlapping squares.

## Fixed

- A test installation can no longer open a window on your desktop. Whether a window opens is decided by what the installation *is*, not by a setting a test has to remember: installing anywhere other than a real install location starts without one.

## Under the hood

- A check now watches where a chat's requests actually go, rather than trusting the configuration, because the configuration looked correct the whole time a chat was talking to the wrong server.
- The guidance files Agent_b reads at startup are no longer published with the source. They still work exactly as before.

## Known

- The connections page and the model availability it reports are unchanged in this release.
