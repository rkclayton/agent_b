# Agent_b v1.41.0

## Fixed

- Turning on the restricted Windows account for tools, or repairing it, no longer depends on your model server. It used to look up that server's address while applying the network policy, so being away from the network that resolves it made the whole step fail and report that the policy had not been applied. The rule never needed it: Agent_b itself makes the model requests, under your own account.
- The network policy is now fixed: the restricted account may reach this machine and the addresses you have explicitly allowed, and nothing else. Changing which model you use changes nothing about it, and there is no longer a warning that it has drifted because an address moved.
- When a step does fail, the first line says what actually went wrong instead of naming a script and an exit code.
- The pairing square no longer disappears while you are reaching for your phone. Codes expire, and when one does Agent_b quietly gets another and redraws in its place. It stays until the phone has paired or you press Cancel.

## Changed

- Settings → About shows one telemetry control, the switch. The receiver line and the list of what was sent are gone, and the window is no longer given them at all. What the switch does is unchanged.

## Under the hood

- The checks for the network policy read the scripts and report; none of them changes anything on this machine. Applying it is still yours to do, with the one Windows prompt.
