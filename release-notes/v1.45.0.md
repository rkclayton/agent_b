# Agent_b v1.45.0

## New

- Profiles can hold named skills with instructions and supporting files. Import a skill in Settings → Profiles, review its source and warnings, then enable it for future chats.
- The file reader can list ZIP archives and read text or Office files inside them without unpacking the archive.
- Setup asks whether to send anonymous usage counts, using the same choice available in Settings → About.

## Fixed

- Settings → Phone distinguishes not paired, waiting for a phone, phone connected, and broker unreachable states.
- A missing file path points to a matching file inside a nearby ZIP archive or one folder deeper when possible.

## Security

- Imported skills arrive disabled, skill folders are read-only to chats, and scripts retain the normal command approval rules.
- ZIP reads refuse unsafe member paths, excessive expansion, excessive compression, oversized members, and excessive member counts.
