# Agent_b v1.44.0

## New

- Settings → Security → Credentials can connect a Microsoft Entra account. Sign in through a browser or with a device code, switch accounts, and sign out from the same section.
- Service connectors can deliver binary responses such as workbooks and PDFs into the chat's folder. The result appears as a file chip with its size and fingerprint.
- When a command or script reaches outside the chat's folder, the approval can apply once, for the chat, or to that folder. Saved folder approvals are listed in Settings → Security.

## Fixed

- The chat composer can be dragged completely shut, remembers that position, and opens again from the same handle without losing typed text.
- A paired phone remains paired across an Agent_b restart and reconnects automatically. Revoking it removes only the pairing while preserving this computer's identity.

## Security

- Entra access tokens stay in memory. The refresh cache is protected for the signed-in Windows user, is bound to the configured service origin, and is cleared when access is revoked or the account is signed out.
- Delivered binary responses are size-limited, written atomically, and refused if they reflect a credential sent with the request.
