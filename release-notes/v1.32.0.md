# Agent_b v1.32.0

## Fixed

- Adding a server could not be saved until it had been tested. Typing a name, an address or a key left the Save beside the connection dead: the button carried the state of the last time the page drew itself, so nothing happened when it was pressed and nothing said why. A test redrew the page, which is why testing first appeared to be the price of saving. Save is live the moment there is something to save now, and renaming a connection and saving it is one step with no test in it.
- Test wrote a port into the address you typed. If the address carried no port, Test tried the usual ones, picked whichever answered — including one that answered with no models at all — and put it in the field. The address is yours: a port you typed is the only one tried, and an address with no port comes back with a line saying what each port answered ("`:8080` — 3 model(s) · `:11434` — answered, no models · `:8000` — nothing") and the field exactly as you left it. You add the port.
- Test said "testing" and nothing else. It shows the same progress bar the updater shows, inside the button you pressed, from the frame you press it, with a line naming what it is doing and which address it is doing it to. The Evaluation Harness shows the same bar, counting the briefs it has run and naming which half of the comparison it is in.

## Changed

- The settings for a connection now read top to bottom the way you fill them in: name, address, key, Test, model, Evaluation Harness, Save. The settings that only mean something once a model is chosen are not shown until one is, and Advanced sits collapsed below Save.

## Under the hood

- The six things this release claims are written as checks that run before every release: three against a recording of two real model servers — one serving three models, one serving none — and three in the browser, including a screenshot taken a tenth of a second after Test is pressed.
