# Agent_b v1.60.85

- The agent is no longer stopped for saying what it will do, capped on turns or tool calls, cut off from its tools, or denied a waiting approval unless you marked the job unattended.
- Every rule that can stop, refuse, or cut work is listed under Help > Rules.
- The agent can add or change an installed skill after asking you first.
- Memory keeps notes within its saved limit, leaves them out of every prompt, and lets the agent recall them when needed.
- Allowed folders are readable in Settings; allowing a folder covers its subfolders, and the list shows only the parents.
- Undoing a turn's file changes works all at once or one file at a time.
- A running chat opens on the phone.
