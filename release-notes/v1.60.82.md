# Agent_b v1.60.82

- Long chats now make room for themselves in one pass.
- A chat stuck at its context ceiling takes the next message and carries on.
- The chat menu lists agents by name.
- A run's changed files open as diffs and can be put back one at a time or all together.
- Agents can show task lists and ask questions with choices or a typed answer.
- Agents can start, inspect, use, wait for, and stop background processes.
- Connections support MCP servers over local commands or Streamable HTTP.
- Machine hooks can run before or after a call and when a run ends.
- Pictures can be added to chats and resized when needed for the selected connection.
- A backup connection can continue a chat when the main connection does not answer.
- Code navigation reports errors, definitions, references, and file structure through an installed language server.
- Setup offers a separate Windows account for the agent's commands.
