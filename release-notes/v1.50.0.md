# Agent_b v1.50.0

## Improved

- Per-user install, update, and uninstall now use native Windows operations, so managed PowerShell execution policy no longer prevents installation.
- Service identity setup now uses a signed native helper for the local account, folder protections, and typed firewall policy.
- When Windows policy disables scripts, the installer and Settings name the effective policy and scope while the app remains usable as the signed-in user.
