# Agent_b v1.60.82

- A long task in a nearly full chat no longer stops at the context limit after an earlier run had failed.
- The chat now says why when its context cannot be reduced.
- With models that report their own token counts, a run no longer stops a tenth early.
- Settings from releases more than twenty versions old are no longer converted directly; such a copy is told which release to install first.
- When a chat fills, everything but your current task and the most recent work is now replaced by a single summary, in every kind of run.
- If a summary cannot be written, the chat still makes room and says so.
- Compaction no longer happens in small silent steps.
- A service marked for confirmation now asks before it makes a call.
- A working agent can show a short task list and ask one question with choices or a typed answer.
- A finished run shows how many files its file tools changed and can put all of them back after confirmation.
- The changed-file count opens a file-by-file diff, and any one unchanged-since file can be put back without touching the others.
- A run can start a local background process, inspect its output, send it input, wait for it, and stop it without orphaning it.
- MCP connections now support both local command servers and Streamable HTTP, including discovery, schemas, calls, and bounded lifecycle cleanup.
- Machine-configured hooks can run before or after a call and when a run ends; a before-call hook can refuse the call without bypassing its normal approval.
- Large images are resized before they are sent to a model, keeping their proportions and recording the change in the chat.
- The shell tool can open a web page in an installed browser and save a screenshot without taking over the desktop.
- A connection can name one fallback connection; when its model cannot answer, the chat continues on that fallback and says so visibly.
- The chat's menu now lists your agents by name, with each one's connection beneath.
- A chat keeps the agent you chose, and its opening prompt, whatever its connection.
- After Agent_b edits or writes source, an installed language server reports errors and warnings in the tool result.
- Agent_b can ask an installed language server where a name is defined, who uses it, and what a file or folder holds.
- Independent read-only tool calls in one reply now run four at a time while changes remain ordered barriers.
- Connections to provider-owned endpoints now use their native protocols, including streaming, tools, images, reasoning continuity, and provider token usage.
- A chat can send writing tasks to isolated helpers, including helpers on another approved connection; each return is either applied whole or reported as a visible collision.
- Setup now offers to run the agent's commands as a separate Windows account.
- You are told if that account is switched off at start-up.
