# Agent_b v1.25.0

## Fixed

- The Update button works. The installer was rejecting a workspace folder whose name it did not recognise, even when that folder sat inside Agent_b's own directory, and every update failed on it.
- A failed update now says why, in the installer's own words, and keeps offering the version. It used to return silently to "update available" with nothing shown, because Agent_b only ever learned that the installer had *started*, never what it then did.
- The message box can be dragged down to a single line. It used to stop at three lines' worth of height however far you dragged.
- The message box cannot be dragged shut, so it can't be lost.
- The status strip above the message box is now the height of its own text. A 24-pixel control inside it was making it taller than it claimed to be.
- Both ends of that strip are inset the same amount; the attachment control used to sit hard against the window edge while the text kept its margin.
- The attachment control is drawn smaller there and is exactly as easy to click as before.

## Changed

- Plan is a tab in the strip alongside your chats, pinned at the far right, instead of a separate control off to one side.
- The Plan tab stays where it is when chats open, close or reorder, and carries no run state, because it is not a conversation.
- Right-click the Plan tab to hide it. You are asked first and told it can be turned back on in Settings, where there is now a switch for it under Chats. Hiding keeps everything about the page.

## Under the hood

- A tab now points at a surface rather than at a chat, which is the groundwork for opening one in its own window later. Nothing else moved.
- Two chats working in the same folder from separate working directories could overwrite each other's files without warning. File conflicts are matched on the file itself now, so they see each other. Writes made by shell commands are still outside that check, and the reference documentation says so.
- The wire format for talking to a paired phone is now written down with test vectors, so the phone and the desktop cannot drift apart. Nothing in this release contacts a phone.
- Agent_b no longer names other companies' models when describing itself.

## Known

- The connections page and the model availability it reports are unchanged in this release.
