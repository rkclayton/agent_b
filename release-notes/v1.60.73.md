# Agent_b v1.60.73

- After an update started in the app, the window reopens by itself.
- A slow first start after an update is no longer reported as a failure.
- A working chat's name now glows back and forth more slowly.
- The agent's messages use the full width of the chat.
- The robot is redrawn with a solid head, lamp, ears, shoulders, and clearer eyes.
- Beside a working chat, the robot now shows whether the agent is reading, thinking, writing, or running a tool.
- Settings now grows with the window.
- Each setting's value sits beside its name, with unnecessary explanatory text removed.
- Activity shows tool use and totals as tables for the selected profile.
- A profile's tools are a compact list, and its notes are a table behind a button.
- Notifications has separate entries for Windows desktop and phone.
- Security lists Allowed Directories as a table and groups Service identity and Docker Sandbox under Experimental.
- The Unattended, Standing grants, and Users sections are removed.
- The Plan page now adds a project by its folder and shows its plan, chats, and changes; Auto-continue is removed.
- Skills has its own section, where each skill can be switched on or off per profile and added by choosing its folder.
- Skills you add can be replaced or removed, and Add skill also accepts a folder containing several skills instead of using a separate import.
