# Agent_b v1.60.56

- v1.60.54 could not be installed because its embedded application was signed with the disposable test key. This release replaces it, along with v1.60.42, v1.60.43 and v1.60.51, which carried the same unacceptable payload signer.

- Release deployment now asks the completed installer the same pinned-signature question that installation asks, before publishing anything, then downloads the public installer and asks again. A release whose embedded application is not signed by the pinned release key is refused before publication.

- An update started inside Agent_b now checks that full installer verdict before launch. A refusal or an early installer failure appears where Install was pressed and offers Install again. After a successful in-app update, Agent_b returns in its window on the same chat; command-line, deploy, sign-in and disposable-test install paths remain windowless.
