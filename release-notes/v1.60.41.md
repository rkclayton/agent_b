# v1.60.41
- New Chat now works after every chat is deleted, and sending with no chat open starts one automatically.
- Window controls respond across display scales and record each press for diagnosis.
- Chat names use the full list width, menus dismiss on an outside press, and the list narrows smoothly to hidden.
- Settings no longer offers a default voice chat; spoken requests must name their chat.
- The Settings, New Chat, and new-folder controls now match the surrounding text-sized glyphs.
