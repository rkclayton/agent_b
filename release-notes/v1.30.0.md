# Agent_b v1.30.0

## Fixed

- A console window appeared at startup, showing the first few lines of the log, however many times it was asked to stay hidden. The Start Menu shortcut ran the program directly, and Windows gives that kind of program a console of its own; the shortcut now starts it the same hidden way every other shortcut does.
- Repair, under Settings → Security, failed on every machine with a message about not being able to convert a value to a switch. One argument was quoted, so the step below it received the word instead of the switch and stopped before doing any work. The argument is removed; what it asked for was already being done.
- An update that had worked was reported as having failed. The last line written by the installer was a note about a folder it could not remove, and the last line is what the screen read as the result. A note is a note now, and the finish is the last line.

## Added

- Update is a sequence you can watch. One line names the stage in hand — downloading, with how much of the download has arrived, verifying it, stopping the running copy, installing, starting the new version — instead of saying "downloading and verifying" from the first moment to the last.
- When Agent_b comes back after an update it says so where the Update button was: "updated to v1.30.0" with the time, until the next check for a newer version. A failure says which stage it stopped in, in the installer's own words, and names the file holding the full account.
- A note the installer leaves behind — something it could not clean up, which does not stop the update — is shown under that outcome as a note rather than as a failure.

## Changed

- The Plan moved out of the strip of chat tabs and into Settings, as its own top-level section, after Agents and Activity. The page itself is unchanged, its address still works, and the switch under Settings → Chats that used to hide the tab now hides the section.

## Under the hood

- Every way of starting Agent_b that the installer registers is now launched by a release check that watches for a console window appearing, and a shortcut aimed straight at the program fails it.
- The release check for updating walks the same readout the screen shows while an update runs, and starts the copy the installer produced to confirm it can state what happened.

## Known

- Repair may still fail for a reason particular to your machine. What changed is the reason it gives; the message and the log it names are what to read if it does.
- Hiding the Plan hides the way in, not the page: its address still answers, and nothing it holds is discarded.
