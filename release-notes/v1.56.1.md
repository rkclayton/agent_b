# Agent_b v1.56.1

## Fixed

- Importing a skill from Settings now uses the folder you entered, even if Settings redraws before you press Import, and says plainly when a folder cannot be imported.
- Skills are on as soon as you add them by import, chat approval, or placing a folder in the profile. Turn one off with its switch in Settings → Profiles.
- Every profile now has its skills folder, and Rescan immediately shows a valid folder placed there.
- The updater-cycle release check now identifies the installer target from its own log instead of ending without a decision.

## After updating

- Open Settings → Profiles. Imported and dropped-in skills appear enabled; use the switch beside a skill if you want it off.
