# Agent_b v1.14.0

## Settings apply when you set them

The Save button that stretched across the whole sheet is gone, and so is the close
`×` beside it — you leave Settings by clicking Chat or Plan, as you would expect.
Almost every setting now takes effect the moment you set it, and the row says
"applied". Four settings still wait for an explicit save, because a half-typed one
means something different from a finished one: the memory directory, the
ignore list, the operator commands and the shell deny list. Each of those carries
a small save icon of its own, beside the setting it belongs to. Nothing else can
be lost by navigating away, because nothing else is pending.

## Each connection carries its own actions

A connection's row now ends with four actions: **save**, **TEST**, **duplicate**
and **delete**. Test contacts the address once and fills in what it learns, using
whatever is currently typed in the fields. Save commits that connection and
nothing else. The Evaluation Harness keeps its home inside the editor, where it
belongs.

## Deleting asks in a small popover

No button rewrites itself into a confirmation under your pointer any more. A
remove control keeps its label and position, and a small popover appears beside it
naming what will be removed, with Cancel and Remove. Escape or a click outside
cancels. Every remove control in Settings behaves the same way.

## Activity is laid out again

Activity had three separate scrollbars inside a page that already scrolls, and
fixed-height rows that left empty space at narrow widths. It is now one page: the
page scrolls, nothing inside it does, and each row is as tall as what it holds.
Nothing was removed — the same numbers and the same controls, closer together.

## Copy takes what you selected

Selecting a few words in a chat and copying gave you the whole turn, including its
collapsed step summaries. Copy now takes exactly what is selected. Collapsed
`steps · …`, `thought …` and `tool … → ok` rows are left out when a selection
crosses them. A speaker's name is added only where the speaker changes, so copying
inside a single message gives you the words and nothing else.

## Drag the strip to resize the message box

The strip between the transcript and the message box is now a handle: drag it up
or down and the message box takes that height, smoothly, and remembers it. The
fixed-height expand control is gone. What you have typed is never disturbed.

## A plan icon, and a line about planning

The Plan entry in the top bar carries new artwork, and the Plan page opens with the
full-quality version of it and three lines saying what a plan actually is.

## Size refusals, whatever status they arrive with

v1.13.2 learned to recognise a server refusing an over-large request and to shorten
the conversation until it fits — but only when the refusal arrived as HTTP 400. It
is now recognised by what it says, under any status.

## Updates can be tested before you get them

The updater passes its own install location to the installer, so a disposable copy
of Agent_b can update itself without touching your installation. That path — read a
release, download it, verify it, install it, come back on the new version — now
runs as a gate on every release, beneath a temporary folder and with no network.
