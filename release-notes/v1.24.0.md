# Agent_b v1.24.0

## The model switcher says which model it is offering

It showed a label, a host and a state, and if the label was `server-2` that told
you nothing — you had to already know which machine was which. The row names the
model now. A llama.cpp model is a long file path, so it is shown by its filename
with the whole path on hover, and it is not truncated: the column had a 90-pixel
floor inside a 680-pixel menu, and a cut-off model name identifies nothing.

A connection that has never been tested says so, instead of naming a model
called "model" that does not exist.

## Code blocks keep their language, and copying stops looking like attaching

The renderer read the language off a fenced block and threw it away, so nothing
told you whether you were looking at PowerShell or JSON. It keeps it now and
shows it quietly. A block with no language renders exactly as it did.

The copy control was a paperclip — the same glyph that means "attach a file" one
surface away. It is two overlapping squares now.

The system prompt asks for fenced blocks with a language tag, in one line.

## A test install can no longer open a window on your desktop

That was prevented by an environment variable, which is exactly the kind of
thing a future test forgets to set — and five of the six test paths that install
did not set it. It is now decided by what the install *is*: an install to
anywhere other than the two real install locations starts without a window. A
real install is unchanged, because starting after installing is what you want.

## Under the surface

A gate now watches **where a request actually goes** rather than what the
configuration says, because the configuration looked right the whole time a chat
was talking to the wrong machine. Two chats on one agent, each pointed at a
different server, and the test checks which server received each one.

`AGENTS.md` and `CLAUDE.md` are no longer published in the public repository.
Both still sit on disk and still work exactly as before.

## Known

The connections page and the model availability it reports are still unchanged.
That work needs a model installed on the Ollama machine to measure against, and
there still is not one — the check was made again and it still lists nothing, so
that work was not begun on a guess for the second release running.
