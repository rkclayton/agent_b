# v1.60.110

- Settings → Chats offers seven background colours, kept across restarts and profiles. The window texture is more visible.

- Installed startup and signature inspection use native Windows APIs, including when PowerShell scripts are disabled.
- Local model installation failures name the failed step and an action to take. A bounded local model-install.log retains diagnostic steps; model-install telemetry is documented but is not sent yet.
- Browser data in Security has a hover explanation.
- A server refusing a request's size ends that run with the server's explanation, without changing saved context limits or retrying a smaller request.
- Silent phone links disconnect after 90 seconds, and connection attempts end after 15 seconds, including pairing attempts.
- Queued phone messages read agent instructions safely during profile refresh.
- Retry remains available after a chat error redraws.
- Paired phones receive chat lists without copying the newest chat's transcript. An oversized reply is refused before advancing encryption state, so its error can still be read on the same session.
- A phone session ended locally records its existing close reason in the link log.
- Repeated setup launches share one installation: additional copies exit immediately while the first keeps its progress and finishes.
- Local models check required runtime components before downloading. Missing components can be installed after confirmation, with signature verification and clear cancellation or restart results. The unpacked runtime must start successfully before a model downloads.
- Cleanup preserves the ten newest planning snapshots. Chat verification follows Archive, current setup controls, and streamed text.
