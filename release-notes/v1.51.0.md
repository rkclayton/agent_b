# Agent_b v1.51.0

## Improved

- New chats understand their private working area, show the folders you have shared, and ask which folder to use when a file request has no location.
- Anonymous diagnostics now go to the public intake when enabled, and Settings shows the destination host.
- A paired phone can see the safe capability summary for each PC connection and choose one when it creates a chat.
- Organisations can stamp staged releases with their own code-signing certificate while the installer independently verifies the Agent_b payload signer.
- Administrators can point updates at an organisation-owned HTTPS release endpoint without weakening manifest, checksum, identity, or signature checks.
