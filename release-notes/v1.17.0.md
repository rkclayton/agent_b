# Agent_b v1.17.0

## Every role can be pointed at a model

Settings → Agents became a table last release, but only **b** — the one you talk
to — could actually be re-pointed from it. **c** the worker and **d** the planner
showed the model they were configured with and nothing more. All three are
settable now.

Each row says when the change takes effect, and it says it accurately. Changing
**b** waits for that agent to go idle, as it always has. Changing **c** or **d**
takes effect on the next run that reads it — which includes the next summary or
background call inside a conversation that is already going. A conversation that
is already running stays on the connection it started with; nothing is moved out
from under it.

A role with no connection is a normal state and the picker offers it. **d** only
appears when there is a planner, and the change is refused underneath as well as
hidden, so the page is a convenience and not the guarantee.

The page also takes the full width now. It had been sitting in a 300-pixel column
beside an empty one.

## Where a run's time went, in a sentence

Every run already recorded how long the model took, how long each tool took, and
how long it sat waiting on you. Nothing added it up.

A finished run now ends with a line:

> Took 2 min 10 s — the model 1 min 40 s (mostly writing), tools 18 s, waiting on
> you 12 s; one retry.

Largest share first, in plain words, and nothing under five per cent is mentioned
— a short run just says **Took 6 s.** The exact figures are on hover.

**Nothing is guessed.** Some model servers report how much of their time went on
reading the conversation versus writing the reply, and some do not. When yours
does not, the hover says *not reported* and the sentence makes no claim about it.
A figure that was never measured is never shown as a zero.

Settings → Activity gains the same numbers per connection, lifetime beside the
last twenty runs: how many runs were measured, the median, the split between
model, tools and waiting, and the rates of empty replies, tool errors and
repeated calls. Two columns rather than one, because a lifetime average cannot
show you that a connection has got worse lately.

Runs recorded before this release carry none of these figures, and every surface
shows nothing for them rather than a row of zeros.

## Search stopped running two engines short

Two of the search engines had been switched off since 23 September for a reason
that had stopped being true within days, and nothing in the product could tell
anyone that. Both were tested against a live query, both returned full results,
and both are back.

Two others were tested and removed for good: one now serves a proof-of-work
challenge instead of results, and the other blocks the request outright. They are
recorded with what they answered and the date they answered it, so nobody
wonders where they went.

A rate limit is no longer treated as a broken engine. An engine that asks you to
come back later is now set aside for as long as it asked — bounded at both ends,
because that is a number a stranger supplies — and the reason and date are shown
with it. Previously it took three failed attempts to notice, and the result read
the same as a parser that had stopped working.

## Smaller things

The launcher used to end a log with `Agent_b stopped with exit code .` when
Windows would not tell it the code. It now says so in a sentence, and names the
three things it can mean.

The installer's transcript names the registry key it actually wrote, rather than
the one usually used for that install mode.

A release check that compares the version in an order against the tag being
pushed had been reading two of the last nine releases and quietly approving the
rest. It reads all nine now, and a check that finds nothing to read is a failure
rather than a pass.

## For anyone building on the data

The projection format — what a client receives and replays to rebuild a
conversation — now ships with twenty recorded examples taken from real
conversations kept as test material. A gate re-plays all of them on every change
and names the first difference, so a change to the format cannot reach a client
unnoticed.

## What did not ship

Item 2ji also asked for these figures to be sent as telemetry, with the receiving
side's report broken down by model class. **That half did not ship**: there is no
telemetry document, package or receiver in the product yet, and the part that
could be built honestly — the numbers themselves, on the wire, with no text —
is what you have. The receiver is carried forward.
