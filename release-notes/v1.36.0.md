# Agent_b v1.36.0

## Added

- Your phone can reach this Agent_b when you are not at home. Set an address in Settings → Security under "Phone away from home", press Pair a phone, and type the code it shows into the phone. Both screens then show the same ten groups of four characters; compare them, and only if they match do you confirm. Agent_b dials out to reach it — nothing on this machine listens for the phone, and no port is opened.
- The service that carries those messages cannot read them. It sees who is talking to whom and how big each message is, and nothing else: the two ends establish their own encryption with keys the service never holds, and every message is sealed under them. The same is true of a notification: the line it carries is sealed to your phone, and the service forwards it without being able to open it.
- The phone speaks to exactly the routes this Agent_b publishes, by name rather than by address, and each one is served by the same code the window on this machine uses. A request that arrives twice is executed once. A new chat started from the phone carries a name and nothing else, so a phone cannot choose which model it talks to.
- Settings → Security shows what the connection is doing, which device is paired, and Revoke. Revoking ends it from either side, and a revoked phone is refused when it tries to come back.

## Under the hood

- The wire format is re-derived from the service's own published test values, in both roles and byte for byte, before any of it is used: fifteen values, five refusals it must refuse, and three sealed notification payloads. That check was written and committed before the code that satisfies it.
- Six scenarios run against a scripted service on this machine — a request and its answer, a retried request executing once, a resend after a dropped connection re-encrypting under the new keys, a restart, and a newer connection winning — and the whole thing ran end to end against the live service, which is where the pairing, the session and a real round trip were proved.
- The release checks gained one more: a tool this Agent_b runs cannot reach the phone connection or its keys.
