# Agent_b v1.39.0

## Changed

- Pairing a phone now works out of the box. Settings → Security under "Phone away from home" has no address to find, type or keep up to date: press Pair a phone, point the phone's camera at the square, and compare the ten groups of four characters as before.
- The address that makes that work is built into Agent_b and is not shown anywhere in the window. There is nothing to copy by mistake and nothing to get wrong.
- Agent_b connects out only while a pairing is under way or a phone is paired. An install with no phone opens no connection at all.

## Under the hood

- A checked file can still name a different service for anyone running their own; it is read from the file only, never from the window.
- Proved on a throwaway copy with no settings of any kind: the section shows no address, pairing reaches the public service, the square was read back off the screen, a stand-in phone paired from it, and Revoke put it back to none paired.
