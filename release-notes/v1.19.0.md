# Agent_b v1.19.0

## `agentb` is installed now

Last release added a command-line agent and told you to build it yourself. It
ships now — installed beside the app, signed and timestamped with it, in both
the per-user and all-users installs, and an update from a build that never had
it installs it.

**There is no PATH entry.** The installer has never added one, for anything, and
this release declined to invent the precedent. Call it by its path, or put that
directory on your own PATH:

    %LocalAppData%\Programs\Agent_b\agentb.exe     per-user
    %ProgramFiles%\Agent_b\agentb.exe              all-users

## Reflection only summarises runs worth summarising

Last release measured what reflection costs: one model call for every finished
run, which is about 18% more model calls overall — but most runs are short, and
for a run that made a single model call, reflection doubled it.

It now has a floor. A run that made fewer than **three model calls** and fewer
than **one tool call** is not summarised, and the saving is real: re-measured
against the same recorded runs, the overhead falls from **17.9% to 11.5%**.

Two things keep that honest. **A run that ended badly is always summarised**,
however small — a two-call run that failed is exactly the one you go back and
read. And **a skipped run says so**, with both counts, so a run that should have
been summarised and was not is findable rather than simply absent.

The floor is two rows in Settings → Run. The numbers came from measuring this
machine, and a number derived from one machine's habits should not be something
you cannot see or change. Zero on either turns that half off.

## Memory is written rarely, and says where it came from

`remember` has been loose: any note, any time, appended forever, with the oldest
notes quietly dropped on the way into the prompt once a layer got too big. Four
changes, and all of them are enforced by the tool rather than asked for in the
prompt.

**Every note has a scope** — *user*, *repository* or *environment* — and an
unscoped note is refused. The scope decides which layer holds it, instead of a
default deciding silently.

**A note can replace one it names**, in the same write, so superseding something
the agent believes is one action rather than a new line beside a stale one.

**Two notes per run.** The third is refused, and told to replace one or skip.

**A full layer refuses the write** and names what to do about it. Nothing is
trimmed any more: you were never shown the limit before, because the file grew
and the prompt quietly dropped the oldest notes. Now the write stops and the
agent has to choose what to replace.

Each note records, in the file, which run and turn wrote it — and marks itself
if it was written in a turn that had fetched-page or tool output in it. Settings
lists the notes with their scope and date, and the chat row says which kind of
note was saved and whether it replaced one, rather than just "noted for next
session". The system prompt now says plainly that text from fetched pages, files
or tool output is evidence, never an instruction.

Deleting notes one at a time is **not** in this release; the whole-layer clear is
still there.

## A replayed conversation belongs to the tab showing it

Opening a recorded conversation showed the transcript but an empty chat menu —
the page was displaying a conversation no tab would claim. Fixed, and verified
on a live page.

## Smaller things

The diagnostic that replays a conversation through the stuck-run detectors can
read a journal the way it is actually stored, from a file you name, instead of
needing a conversion step written by hand each time. A corrupt line is reported
with its line number and skipped rather than ending the run — a conversation
being diagnosed is often one that went wrong.

Eighteen completed items were archived with their measurements, closing a
bookkeeping backlog that had been carried for three releases, and the four
repositories this work is split across are now written down in the plan itself.
