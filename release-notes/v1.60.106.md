# v1.60.106

- Thinking appears in one row that opens the live reasoning. A finished thought stays in one row above the answer.
- Installed models start on demand and stop when idle or when the app quits. Settings can start, stop, change or remove them and set the idle timeout; no model sign-in launcher is written.
- Added paired-phone protocol support for model state, start and stop.
- Local servers can save start and stop commands, use the same on-demand and idle controls, and be started or stopped from a paired phone. Command text stays on the PC.
- Settings can store SSH logins and answer a matching password prompt once without putting the password in the chat. Logins stay unavailable to phone-origin runs.
- Settings can ask before stored credentials are used, once or for the current chat, with configurable idle expiry.
- Replies can use the free context instead of a saved output limit. Connections has no reserve setting, and a cutoff keeps the partial answer with its explanation below it.
- Settings uses reported context size and keeps derived connection controls under Advanced. Six tool output limits grow with context; saved overrides remain in force. Each connection controls its own concurrent runs.
- Fixed repeated saves when the profile editor redraws an unchanged name.
- Fixed a new message being answered with a harness note after the previous reply was stopped or cut off.
