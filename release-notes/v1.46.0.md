# Agent_b v1.46.0

## New

- Chats now live in real folders under the profile's `chats` directory, so folders and moves made in File Explorer appear in Agent_b automatically.
- The chat-tab menu can create, rename, remove, and collapse folders, move chats by drag and drop, and permanently delete a chat with a red ×.
- Settings → Chats shows the chat directory and can delete all chats with one confirmation while retaining memory notes, plans, and files.

## Improved

- Choosing a chat from a tab's menu replaces that tab with the chosen chat instead of opening another tab.
- Code fences use an aligned shaded panel with a separate language and copy-control header.
- The Jump to latest control is a compact down-arrow at the transcript's right edge.

## Fixed

- Phone notifications work with the current broker protocol, including approval, stopped-run, and stuck-run alerts.
- A disconnected phone session reconnects, answers later requests, and repairs missed state changes.
