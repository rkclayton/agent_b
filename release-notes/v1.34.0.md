# Agent_b v1.34.0

## Changed

- The Plan is a Settings section now, drawn in the Settings pane like Agents, Activity and every other section. Choosing it used to open a separate page with its own address and its own close, and the switch between the two was visible every time. Nothing about the Plan itself changed — the same list, the same document, the same Go — it is simply where it said it was.
- The Plan lays out to the pane it is in rather than to the whole window, and at the narrowest size the window can be dragged to its list and its document stack instead of being squeezed side by side.
- The old address still works. A bookmark or a link to the Plan opens Settings with the Plan section showing.

## Under the hood

- The four things this release claims are written as checks that run before every release, including a screenshot taken a twentieth of a second after the Plan is chosen and one at the smallest window the frame allows.
- One page of markup left the product: there is a single document again, and the Plan's own page is gone from it.
