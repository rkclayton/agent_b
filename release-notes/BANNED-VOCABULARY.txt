# Item 2n9 (d): the words a release note may not contain, in one file so it can be
# extended without touching the gate.
#
# The reader of a release note is ANY USER of Agent_b, never one person. The notes
# up to v1.23.0 addressed the one reader the writer knew: they named a particular
# machine, a particular folder, how many releases had shipped, which repository was
# waiting on what. All of it true, none of it belonging on a page someone else
# reads. NOTES.md is still the place for every one of these things.
#
# FORMAT: one entry per line. Blank lines and lines beginning with # are ignored.
# A line is matched case-insensitively as a whole word unless it is wrapped in
# /slashes/, which makes it a regular expression.
#
# Add a line to forbid a word. Nothing else needs changing.
