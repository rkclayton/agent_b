# Agent_b v1.27.0

## Added

- Settings → About has an Export diagnostics control. It produces one file describing your installation: the build, what the last update check and install attempt did, each connection's last test result, and the recent lines of every log, including any crash record. Paths outside the installation, account names, addresses and anything token-shaped are replaced before you see it, so the file is safe to send to whoever is helping.
- Nothing is measured to make that file. Anything it cannot gather quickly is named, with the reason, instead of being left out.
- Explorer's Send to menu now offers Agent_b, which copies the selected files into the folder Agent_b reads. Nothing already there is overwritten, and anything it could not copy is written to a log beside the folder.
- Settings → Activity lists each note the reflection pass wrote, with the day, the layer holding it and the run that produced it. Each row can be confirmed, corrected, deleted, or restored after deleting.

## Changed

- Confirming a note takes the word "unconfirmed" out of it and records the day you agreed, so the note stops telling the model that nobody has checked it. Correcting a note replaces its words with yours and confirms it at the same time.
- A deleted note is kept for thirty days and can be brought back from the same list.
- Two notes that differ only in capitals or spacing are now one note rather than two.
- A third layer of memory holds facts about this machine, rather than about a folder or about Agent_b itself. Only the reflection pass writes to it.
- Each layer of memory is loaded up to a stated size, and the list now shows what that is.
- Release notes are written for anyone who uses Agent_b. A check refuses a release whose notes name a particular machine, folder, person or internal process, and earlier notes have been rewritten under that rule.

## Known

- The connections page and the model availability it reports are unchanged in this release.
