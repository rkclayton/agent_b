# Agent_b v1.26.0

## Fixed

- The thinking fold opens while the model is still working. It used to flash and shut: a thought changed identity the moment the model began writing its answer, so the fold you had just opened was looked up under a name that no longer existed.
- A fold you open now stays open for the whole stream and through the moment the thought completes; one you close stays closed.
- A chat whose run was cut off by Agent_b closing unexpectedly no longer claims to still be thinking. On restart the run is closed and says whether it was cut mid-thought, mid-tool or mid-run.

## Changed

- A crash now writes a file under the logs folder with the stack, the build and the last known state, and names that file in the launcher log. Nothing was recorded before, so a crash left nothing to read.

## Under the hood

- Dragging the window during a live model stream is now exercised before every release. The crash that prompted this could not be reproduced in four attempts, so the cause is still unknown; the crash file is what will identify it next time.
- Release tooling no longer blames your signing key when a timestamp server times out, and a half-finished release now names the command that clears what it left behind.

## Known

- Closing a chat behaves correctly in every case that could be reproduced, including with a transcript on screen and with a stale selection after a reload, so nothing was changed there on a guess.
- The connections page and the model availability it reports are unchanged in this release.
