# Agents schema (`agents-1`)

All ids are UUID strings and are never reused. Times are RFC 3339 strings. Instruction hashes are lowercase SHA-256 of exact UTF-8 instruction bytes. Revisions are positive integers assigned only by the PC and are immutable; display identity is frozen when a chat binding is written.

|---|---|---|

## Migration

For a legacy chat, recover the prompt text from its release when possible and bind `agent_b` revision 0 to its hash, storing that text. If unavailable, bind `{revision:"unknown",bound_hash:null}` and show **Historical configuration unknown**. Convert the current configuration to `agent_b` revision 1 with the approved baseline. No existing chat is ever bound to the revision-1 hash during migration.
