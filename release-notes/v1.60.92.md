# Agent_b v1.60.92

- Installing over an older copy now works when its settings are too old to read: they are kept beside the new ones and your chats are still there.
- If Agent_b cannot start, a window says why, with the log lines and a Copy button, instead of showing nothing.
- Running the installer by hand always ends with Agent_b open, on a fresh install too.
- An install no longer fails half-way when a file is briefly in use, and a failed one leaves the copy you had.
- Removing Agent_b from Installed apps says that your chats and settings were kept, and where.
- A paired phone gets its chat list newest first, its tokens in fewer updates, and can register for notifications itself.
