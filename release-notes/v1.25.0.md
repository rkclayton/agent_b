# Agent_b v1.25.0

## The Update button works, and tells you when it does not

You pressed Update, saw "downloading and verifying", and were returned to "update
available" with nothing said. It was not the download and not the verification. The
setup was fetched, checked and run — and then the installer refused, because it
required the last part of your workspace folder's name to be `Agent_b` or
`workspace`, and yours is named `scratch`. A folder already inside your Agent_b
directory was turned away. That rule now accepts any folder inside a dedicated
Agent_b directory, and still refuses a drive root or a shared folder.

The second half of that is why you never saw a reason. Agent_b reported that the
installer had *started* and never looked at what it then did, so an installer that
ran and refused looked exactly like one that worked. It reads the installer's own
outcome back now, and a failed update says why, in the installer's words, with the
version still on offer so you can try again.

The release gate that should have caught this had been passing for twelve releases.
Its test workspace happened to be named `workspace`, which the old rule accepted.
It is shaped like yours now.

## Plan is a tab

It was a small chip off to the right, in a bar that held one thing. It is a tab in
the strip with your chats now, pinned at the far right, and it stays there when
chats open, close or reorder. Right-click it to hide it; you will be asked first,
and told you can turn it back on in Settings — where there is now a switch for it,
under Chats. Hiding it keeps everything about it; the page and its address do not
change.

It carries your Plan mark and no robot, because it is not a conversation.

Underneath, a tab points at a *surface* rather than at a chat, which is the
groundwork for opening one in its own window later. Nothing else moved.

## The message box goes down to one line

It stopped at three lines' worth of height however far you dragged the strip. One
line now, measured — and not zero, because a message box you can drag shut is one
you can lose.

The strip above it said in its own code that it was trimmed to the height its text
needs, and it was not: a 24-pixel paperclip was setting it to 28. It is 20 now,
which is its text plus its padding. The paperclip is drawn smaller and is exactly
as easy to hit. Its right edge was also pulled 4 pixels further out than the text on
the left; both ends match now.

The status text was already exactly centred, measured. Nothing was nudged.

## Under the surface

The document two other repositories were waiting on is written: what the phone and
the desktop actually send each other through the broker, with committed test
vectors as exact bytes and a gate that fails if the document and the bytes disagree.
Nothing in this release talks to a broker.

Two sessions working in the same repository from different scratch folders could
overwrite each other's files without either being warned. File conflicts are keyed
by the file now, so they see each other. Writes made by shell commands are still
outside that check, and the reference says so.

Agent_b no longer names other companies' models when it is talking about itself.

## Known

The connections page and the model availability it reports are unchanged for the
third release: that work needs a model installed on the Ollama machine to measure
against, and the check was made again and it still lists nothing.
