# Agent_b v1.13.0

## Images and honest capability reporting

Agent_b now tells the model what the current connection and tool set can actually do with images. On Windows it can render PNG and JPEG files from code and return those files to the chat as ordinary download chips. The claim is captured when a chat starts, so it stays stable for that chat.

This release did not add image generation. It also did not add a new image-reading pipeline: an existing connection that accepts images may still receive them, while other connections use the existing extraction or unsupported response. Agent_b no longer turns those missing capabilities into a blanket claim that it cannot create raster files.
