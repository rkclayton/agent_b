# Agent_b v1.51.1

## Fixed

- Agent_b's own signed installer now runs on Windows accounts that do not trust the release certificate. The outer Authenticode result is reported, a cryptographically broken outer signature is refused, and the embedded payload signature and pinned Agent_b release key remain required.
- If you installed v1.51.0, download `Agent_b-setup.exe` from this release once and run it by hand. Updates from v1.51.1 onward accept a later intact release even when Windows reports the outer certificate chain as untrusted on that account.
