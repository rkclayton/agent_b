# Agent_b v1.35.0

## Fixed

- A connection saved with the word "model" as its model kept it forever. The word was never a model — it was a placeholder an old version created connections with — and every server refused it by name. Two earlier fixes stopped new connections getting it and neither one removed it from a connection that already had it. It is cleared when your settings load, once, and the line that says so names the connections it cleared. The word cannot be saved as a model any more; an empty model still saves, so an address is worth keeping before you have chosen one.
- Picking a model and pressing Test put the old model back in the field. The pick was never lost — Test saved it and so did Save — but the field was drawn from the saved value instead of from your choice, so it looked like it had been thrown away. The field shows what you picked, through Test and through Save.
- A save that is refused now keeps everything you typed on screen and says which connection and which field it is about, on that connection's own row.
- Switching Service identity on told you to use "its Security setup flow" instead of doing it. The switch is the setup now: turning it on creates or repairs the account, applies the folder and network protections and tests the credential, asking Windows once, and it only lands on when the test passes. Turning it off takes effect immediately.
- The Security page said "account not created" beside an account that existed and was simply switched off, which sent you to Repair for no reason. Every state has its own words now, and with the identity off nothing on the page is red and the setup panel stays closed.
- A failed setup is one sentence under the switch, with the log path beside it, instead of a banner, a red heading and a second copy in a box. It no longer tells you to use a control that does not exist.

## Under the hood

- The settings file records a new schema version, so the placeholder cannot come back from an older file.
- Nine checks run before every release for the things above, including one that reads the setup failure messages out of the source and fails if any of them names a control the page does not have.
